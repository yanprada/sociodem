# `src` Folder Overview

The `src` folder contains all the scripts necessary for the Extract, Load, and Transform (ETL) processes used in this project. Additionally, it includes scripts for testing the quality and consistency of the data, as well as various utility scripts that support these processes.

## Key Components

1. **ETL Scripts**:
   - **Extract**: Scripts responsible for extracting data from various sources.
   - **Load**: Scripts that handle loading the extracted data into our database.
   - **Transform**: Scripts that perform data transformations to prepare the data for analysis and use.

2. **Quality and Consistency Testing**:
   - Scripts designed to validate the accuracy, completeness, and consistency of the data.

3. **Utility Tools**:
   - Miscellaneous scripts that assist in the ETL and data validation processes, providing additional functionalities and support.

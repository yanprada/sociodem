# Bronze Medallion Processing Folder Overview

This folder contains all the scripts necessary to process the Bronze Medallion layer of the PostgreSQL database. The Bronze Medallion represents the raw data ingestion and initial processing stage, forming the foundation for subsequent data transformations and analyses.

## Key Components

1. **Data Extraction Scripts**:
   - Scripts that handle the extraction of raw data from various external sources, ensuring the data is brought into the database in its original form.

2. **Data Loading Scripts**:
   - Scripts that facilitate the loading of extracted raw data into the Bronze Medallion layer of the PostgreSQL database.

3. **Initial Data Transformation Scripts**:
   - Scripts designed to perform basic data cleaning and initial transformations. This step ensures that the raw data is in a consistent format and prepared for more advanced processing in later stages.
